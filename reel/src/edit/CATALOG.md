# Edit Component Catalog

Generated by `node reel/scripts/catalog.mjs --markdown`.

## Canvas and legibility contract

`u = min(width,height)/100`. Generic components use hero 9u, title 6u, subtitle 3.4u, body 2.8u, small print max(22px,2.2u), metric 14u, chips >=6u and buttons >=7u. Padding >=2u, radius 1.5u, safe margin 5u; landscape titles respect 10% side margins. Entrances finish within 0.6s; exits within 0.3s. Foreground text uses 70% black panels or solid ink backgrounds. The default white text exceeds 4.5:1 over both white and black footage. One theme accent is used for rails, markers, bars and buttons; button ink is selected for contrast.

Regions describe foreground ink. Footage backgrounds and optical effects intentionally composite under content and do not create collision warnings. Same-track overlapping background media still warn. Reel4 entries retain their fixed geometry and speech-synced timing (`scalePolicy: reference`); SSIM governs those frozen visuals.

## Transitions

| Name | Execution | Look |
|---|---|---|
| fade | TransitionSeries presentation | Crossfade adjacent clips; duration begins at the incoming clip from. |
| slide | TransitionSeries presentation | Push outgoing and incoming scenes horizontally. |
| scenePush | TransitionSeries presentation | Cinematic scene push, using the slide presentation. |
| wipe | TransitionSeries presentation | Directional wipe between adjacent scenes. |
| flip | TransitionSeries presentation | Perspective card flip between adjacent scenes. |
| clockWipe | TransitionSeries presentation | Clockwise radial scene reveal. |
| circleWipe | TransitionSeries presentation | Expanding circular scene reveal. |
| glitch | Overlay | Deterministic displaced scanline bands. |
| rgbSplit | Overlay | Separated red and cyan flashes. |
| lightLeak | Overlay | Warm animated film light leak. |
| zoomBlur | Overlay | Radial streaks with backdrop blur. |
| zoomThrough | Overlay | Zoom blur burst. |
| pixelate | Overlay | Animated pixel grid. |
| checkerboard | Overlay | Checkerboard interference. |
| whip | Reel4 legacy | Original Reel4 whip blur. |
| whip-blur | Reel4 legacy | Original Reel4 whip blur alias. |

Series transitions require adjacent clips on the same track. `at` equals the incoming clip from; duration starts there. An outgoing last-frame hold supplies overlap without shifting any authored from/to or voice/caption clock. The outgoing clip is removed after the transition. Overlay transitions are independent flashes/effects. Invalid series adjacency is reported by qa_layout.
